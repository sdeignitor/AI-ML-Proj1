# Employee Turnover Prediction

A Machine Learning project that predicts employee turnover (attrition) using workplace-related factors such as job satisfaction, performance rating, work-life balance, years at company, and distance from home.

## Tech Stack
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Model Used
- Logistic Regression

## Project Workflow
1. Data Loading & Exploration
2. Train-Test Split
3. Model Training
4. Performance Evaluation
5. Employee Turnover Prediction

## Files
- `employee_turnover_project.ipynb`
- `employee_turnover.csv`
